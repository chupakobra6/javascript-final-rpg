# Ресурсы арены

- `snowfield.webp`, `fighters.webp` и `winter-map.webp` – иллюстрации, созданные в ImageGen для этого проекта. Референс для композиции поля – официальный [скриншот боя HotA](https://h3hota.com/gallery/images/bulwark_combat_prerelease.png).
- `vcmi/` – значки меча и справки команды [VCMI](https://github.com/vcmi/vcmi/tree/e7442187e8aebf76596b2904f512855d58c73bc9/Mods/vcmi/Content/Sprites2x/battle). Файлы `actionAttack.png` и `actionInfo.png` переименованы. Лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `fonts/atai.woff2` – [Atai 2.0](https://github.com/mirnovov/atai/releases/tag/2.0) от novov. Лицензия [SIL OFL 1.1](fonts/OFL.txt).
- `brass-corner.svg`, `leather.svg` и `command-marks.svg` – рамка, текстура и значки, созданные для арены.
- `favicon.svg` – значок арены для вкладки браузера.
